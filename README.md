# Pemweb OBE - Sistem Informasi UMKM Pesisir

## Identitas
- **Mata Kuliah:** Pemrograman Web (OBE)
- **Studi Kasus:** UMKM Pesisir & Technopreneurship (Sistem Informasi & E-Commerce Produk Pesisir)
- **Pendekatan:** Pengembangan Incremental Semester
- **Nama / NIM:** [Nama / NIM]

## Deskripsi Kasus
Proyek web ini dikembangkan secara bertahap (incremental) untuk memfasilitasi pemberdayaan UMKM di wilayah pesisir melalui pencatatan, promosi, dan pemasaran produk lokal (hasil laut/olahan pesisir).

## Alur Pengembangan Incremental
- **Tahap 1:** Staging Dasar HTML (Halaman Utama & Katalog Produk)
- **Tahap 2:** Styling UI & Layout Responsif (CSS)
- **Tahap 3:** Interaktivitas Client-Side (JavaScript)
- **Tahap 4:** Pemrosesan Form & Logika Server (PHP)
- **Tahap 5:** Manajemen Data & Database (MySQL)

## Teknologi
- **Environment:** Laragon 5
- **Stack:** PHP, HTML5, CSS3, JavaScript, MySQL

## Cara Menjalankan
1. Simpan folder proyek di `C:\laragon\www\pemweb-obe`
2. Buka Laragon, lalu klik **Start All**
3. Akses melalui browser:
   - http://pemweb-obe.test
   - http://localhost/pemweb-obe
